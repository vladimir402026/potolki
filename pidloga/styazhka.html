Яку товщину стяжки вибрати для підлоги?

Вибір матеріалу та товщини шару залежить від перепадів висоти перекриття та типу фінішного покриття:

  • Самовирівнювальна суміш (3–15 мм): ідеально підходить для фінішного вирівнювання старої стяжки перед укладанням ламінату, вінілу або лінолеуму.
  • Цементно-піщана стяжка (30–80 мм): використовується для чорнового вирівнювання плит перекриття, приховування комунікацій та облаштування водяної теплої підлоги (мінімальний шар над трубою має бути не менше 30 мм).
  • Демпферна стрічка: по всьому периметру кімнати обов'язково прокладайте демпферну стрічку товщиною 8–10 мм, щоб компенсувати теплове розширення стяжки.
